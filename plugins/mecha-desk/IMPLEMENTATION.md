# AERIS POLAR / 极地白机甲

75 个独立原生组件规格，以及可伸展的原生任务栏皮肤。插件 ID 使用
`com.cyberdesktop.mecha.*`；分类标签为「机甲」，支持 `mecha`、`aeris`、`polar`、
「极地白」和「白隼」搜索。任务栏设置中的「机甲 · 极地白」独立保存。

装甲使用已批准的原始透明 PNG。共享素材位于应用的 `assets/mecha`，实例仅请求自身
可见裁片在当前 DPI 下的尺寸，使用 SDK 的后台 WIC 解码和有预算的共享缓存。
数字、日历、指针、控制按钮、照片、媒体封面和音频响应分别渲染；异步裁片就绪会
使依赖的卡片缓存失效。Chakra Petch、Orbitron 和 Noto Sans SC 的字体与 OFL
许可位于 `assets/fonts/Aeris`，功能图标使用公共 Lucide 入口。

各功能复用现有时钟、农历、天气、空气质量、系统监控、媒体、计时、环境音与
物理模型。胸甲计时核心与指挥计时舱使用真正的时区时钟，不实例化滚珠模型。
悬浮声芯、音脉翼订阅共享系统 FFT，分别按低、中、高频调整装甲运动和接缝；
无声时回到静止。长频谱的作动杆独立显露金属轴并平移端帽，保持部件比例。
翻牌默认显示 `CYBERDESKTOP`，英文显示转为大写，同时保留设置原文以兼容 SDK 的原子读写约定。池塘使用真实水域轮廓约束运动，
鱼体使用同一逻辑尺寸，避免在不同池塘中分别缩放横纵轴；水面互动使用实际点击位置。

`tools/PrepareSuite.py` 将本地设计转成原生注册数据；运行时不读取 `design/`。
原始插件与布局 ID 只作为来源记录，旧布局标识和宽×高占格保持兼容。

专项验证入口：`scripts/build-mecha-desk.ps1 -Jobs 10`。固定输出目录为
`build/relwithdebinfo/Testing/mecha-desk`，包含 75 个规格的原生预览、多 DPI、
缩放、暂停恢复、混合桌面重建、真实控制命中区与 FFT 服务样本检查；另外验证
目录筛选/搜索和 36 个任务栏宽度、DPI、材质缓存及设置重载用例。
每个插件运行 SDK test、cdpkg validate。统一发布使用 `scripts/build-all.ps1`，
唯一运行目录为 `build/dist`。

原生字号与信息层级由 `tools/Readability.py` 注册，设计数据重新导入时也会保留。
文字以可见字形而非字体行盒居中；长曲名、城市、事件名保留最小字号并省略尾部，
过小的可选附字隐藏。圆形计时器的主倒计时与短周边指示分离；仪表指示只在外圈
运动；小表盘仅保留可读的主要数字刻度。竖版数字钟的时、分、秒各自位于深色窗内。
`Testing/mecha-desk/readability` 保存全部 75 个规格的真实 1× 原生输出，另覆盖长标题、
六行月份、99 分钟倒计时，以及精密钟 12 个小时位置的指针范围与主数字像素居中回归。

后续修正：紧凑倒数日只显示独立天数和 `D`，右侧放大并居中显示短日期，
LCD 日期按实际浅色窗居中。镂空钟使用原图的七个独立金属齿轮裁片，按时钟机芯角度与
齿数反向转动；隐藏秒针不停止齿轮，关闭动画才冻结。任务栏采用 Pixel 的整体高度预算，
端部开口、细边和短倒角过渡使用同一套坐标，按钮与悬停高亮限制在深色开口内。
三个锦鲤池改用正俯视素材、闭合水域和正圆涟漪；鱼体直接复用机械主题的实时骨骼绘制，
新实例默认鱼数为 3 / 5 / 5，并按真实水域确定鱼体尺寸。

全套素材清洁由 `tools/ArtReview.py` 注册为原生矢量轮廓，不改写原始 PNG。
使用 `tools/requirements.txt` 安装设计工具依赖；OpenCV 只参与注册数据生成，发布运行时不依赖 Python。
轮廓去掉邻近控件碎片、抠图残点和背景雾块，含阴影的生活组件另按真实底脚裁切。
长条频谱只保留原图的结构轨道，每根实时柱独立绘制，不叠加示范柱或悬浮峰值残留。
圆形频谱使用同一正圆上的 48 根柱体，音频幅度沿柱内 8 段灯带显示；中央声芯和支架保留机甲造型。
沙漏以连续角度投影翻转，换周期时镜像现有沙堆，避免等待尾段及沙粒突然重置。
专项覆盖全部 75 个规格的帧缓冲清理、深浅底色复查、频谱有声/无声恢复和柱端正圆，
以及沙漏周期边界的角度和沙堆位置连续性。

文字复核由 `tools/TypographyReview.py` 固定登记：主数字使用半粗 Orbitron，普通字段使用
中等字重 Chakra Petch / Noto Sans SC，浅底配深蓝文字、深底配亮白文字。可用空间内的
附字不再因可选字号阈值直接消失。日期按表壳窗口重新定位；天气数值与较小单位共享基线，
底部预报按白色长窗居中。LCD 4×1 先裁除透明工作室留白，再按原比例组织边框。
4×1、6×1、8×1 长条沿实际桌面格宽延展显示窗、连接段和直轨；圆形仪表、端盖及装饰保留比例。
所有命中区、文字区域与静态排除区使用同一映射，四边维持至少 6px，左右以 6.5px 登记。
专项增加 80 / 96 / 112 / 128px 砖宽与 1 / 1.5 / 2 DPI 的实际占宽检查。

沙漏玻璃材质保留累计半圈方向，解决换周期时反射贴图翻回初始朝向的闪烁；
在 15 / 20 / 30 FPS 下逐帧检查三次真实渲染周期边界，独立于沙粒位置检查。
声芯按每秒 6° 缓慢转动，静音时保持转动；外圈柱阵不旋转，降低动态效果或暂停后停止。
