CyberDesktop 独立机械仪表插件 — Windows x64 /MT / C ABI 1

在桌面控件列表中直接添加“机械系统监控”“机械网速”“机械磁盘”“机械番茄钟”
“机械天气”或“机械音乐控制”。每个尺寸为独立插件，拥有独立 ID、模块、描述、预览和 .cdpkg。
固定使用机械样式，没有外观切换选项。原来的插件保留原 ID 和原有样式。

尺寸按列×行：
机械系统监控：1×1 / 2×1 / 4×1 / 2×2。
机械网速：4×1。
机械磁盘、机械番茄钟：2×2。
机械天气：2×1 / 4×1 / 4×2。
机械音乐控制：2×2 / 4×1 / 4×2。
机械音乐控制 4×1 与 2×2 使用各自等比的异形 PNG 外壳，与 4×2 共用 PNG 唱片、原图唱臂和媒体服务。
封面占唱片半径的一半；播放时转动，唱臂随进度缓慢向内移动，暂停时停止。曲名、按钮与时间尺按各自外壳排版。
机械空气质量：2×1 / 4×1 / 4×2。
机械环形频谱：2×2；机械柱状频谱：4×1。
机械键鼠计数：4×1。
机械农历：2×1 / 2×2 / 4×4。

机械农历为三个独立模块，使用分别设计的透明机壳、原生日期和中文；轮廓等比居中并保留留白。
2×1 显示公历月日、农历和节令；2×2 提供单日大字盘与翻月；4×4 为四至六周自适应双历网格。
复用 lunar-suite 的离线 sxtwl 算法、1900–2100 日期边界、闰月、节气、节日、选日和状态保存。
机械版仅保留语言、周首及相邻月份设置；按钮与日期格使用相同的绘制/输入变换。
专项构建验证：scripts/build-mechanical-lunar.ps1 -Jobs 10；增量发布：scripts/deploy-mechanical-lunar.ps1。
机械农历 1.1.0：沿用机械月历的 180 毫秒立方缓动，变化的年月日数字在滚轮窗口内上下滚动。
向前、向后翻月使用相反的滚动方向，跨日与返回今天使用相同效果；不变的数字和机壳保持静止。
动画完成后释放 33 毫秒动画定时器，隐藏、恢复状态和“减少动态”时直接显示最终日期。
机械键鼠计数显示两组今日次数，复用已有宿主统计服务，不重复监听输入。
五位显示范围为 00000–99999，超过上限后保持显示 99999，后台真实统计不截断。
机械键鼠计数 1.0.1：数字缩小并上移，分别校准十个滚轮的水平中心，增加均匀留白。
只有变化的数字滚轮短暂转动；稳定、隐藏、暂停和减少动态时停止视觉计时器。
跨日立即复位，统计未运行时显示短横线；界面仅保留数字与键鼠标识。

机械频谱为两个独立插件，使用已确认的拉丝钢机壳、黄铜滑杆和浅色峰值帽。
频段杆使用独立 PNG 材质，按真实音频升降或径向伸缩，保留峰值保持与自然回落。
机械柱状频谱 1.0.1：将上方横线峰值帽替换为独立钢珠 PNG，复用滚珠机械钟同款材质。
钢珠与各升降杆轴线对齐，随峰值弹起、停留和回落；最大振幅时仍留出完整球体的上方净空。
机械柱状频谱 1.0.2：钢珠峰值停留由 180 ms 缩短为 40 ms，下落速度提高为原来的 4 倍。
机械柱状频谱 1.0.3：下落速度调整为最初的 2 倍，保持 40 ms 停留，让钢珠与柱杆拉开可见距离。
机械柱状频谱 1.0.4：进一步减慢到最初的 1.2 倍，延长可见下落过程，保持 40 ms 顶部停留。
环形保持正圆，柱状使用异形细底梁；不显示标题和无关文字，四周保留透明间隙。
复用宿主共享 FFT、灵敏度、回落时间和局部刷新；静音后停止重绘，隐藏时释放订阅。
专项入口：scripts/build-mechanical-spectrum.ps1 -Jobs 10。

机械空气质量使用已确认的三表设计；4×2 中间仅保留两段连接桥与一个完整开放空隙。
仅显示地区、AQI 及 PM2.5 / PM10 分项指数，紧凑 2×1 仅显示 AQI。界面不显示来源、预报或说明段落。
分项仍为现有 US AQI 数据接口提供的污染物指数，不添加浓度单位；缺失数据为 --，缓存读数保留短状态。
机壳、实时刻度、指针与读数分层绘制，四周留白、圆形零件等比适配。图形及数据许可保留在包内。
新增空气质量与机械弹簧钟、风铃的专项入口：scripts/build-mechanical-air-toys.ps1 -Jobs 10。

底层复用公共绘制部件和原有的数据服务。数字立即显示真实读数，指针短暂缓动。
新实例默认采用常规界面字体，读数与标签分区；较小尺寸会减少次要信息，避免过度缩字。
计时按钮等宽，音乐控件按横条、方块与宽面板分别排版。字体仍可在每个实例中独立设置。
隐藏或减少动态时停止视觉动画。网速表采用对数比例，数字始终显示准确速率。
番茄钟按实际截止时间继续计时；音乐按钮遵守媒体会话的能力位，暂停后唱片停转。
天气保持 Open-Meteo 来源与原有定位设置；机械系统表缺少温度数据时显示 —。
每个插件均可独立添加、设置、移除和安装，互相不影响。

1.0.1 更新截图中的四个独立插件：机械番茄钟、机械磁盘 2×2，以及机械天气、机械音乐控制 4×2。

机械相册 4×2：拉丝金属外框；鼠标悬停或键盘焦点显示机械上一张、暂停/继续、下一张按键与计数窗。
双击相册照片或金属外框，用同目录 CyberImage 图片浏览器打开当前原图；机械按键与计数窗不触发打开。
默认开启照片缓动：使用 CyberCanvas/Tweeny 正弦缓入缓出，12 秒单程微缩放和平移，金属外框与机械按键保持静止。
暂停轮播或隐藏时停止缓动；设置中可关闭“照片缓动”或启用“减少动态效果”，同时遵循 Windows 动画偏好。
相册设置可选择图片目录、子目录、轮播间隔、淡入时间和完整显示/居中裁切；暂停轮播状态独立保存。
图片扫描和解码复用 widget-suite 的后台 Album/WIC 实现，静止时不持续请求刷新，隐藏时停止定时器。
