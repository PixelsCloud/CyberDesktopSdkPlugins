# CyberDesktop Clock 1.0.0

数字钟和模拟钟各四款独立插件：1×1、1×2、1×4、2×2，另有翻页卡片时钟 2×2、1×4、2×4，共十一款。尺寸是行×列，1×4 占一行四列。所有插件使用 SDK 1 的 C ABI 和 protobuf 单文件包，Windows x64、MSVC `/MT`，不依赖 Qt 或动态 VC 运行库。

## 构建和发布

```powershell
./plugins/clock-suite/build-clock.ps1 -Jobs 10
```

默认读取 `build/dist/sdk`，可用 `-SdkRoot` 指定已安装的公开 SDK。输出 `build/clock-release/artifacts` 中十一份 `.cdpkg`、目录索引和 SHA256SUMS。只发布 `.cdpkg`；不必另行分发 DLL、描述文件或设置文件。包内包含说明与 SDK MIT 许可证。

核心文件为 `Clock.cpp`（时间、实例、缓存、布局、设置）和 `ClockRenderer.cpp`（DirectWrite 文本、Direct2D 表盘），`Plugin.cpp` 为统一 C 导出入口。时钟以本地系统时间为准，支持 UTC 和固定分钟偏移，无网络请求。

## 自适应显示

插件按宿主传入的实际安全区域和 DPR 绘制，而非假定每格正方形。数字钟在窄长的 1×1 / 2×2 中自动纵排，模拟表盘始终为圆形。1×4 保持横排。内容透明，砖面、阴影、涟漪由宿主负责，不覆盖主题材质。

1×1 数字钟默认在纵排时显示秒数，正方形时隐藏秒数；设置“秒数排布”为“始终显示”即可改变。1×2 数字钟默认不显示秒数。小尺寸会缩小字体、简化日期和表盘刻度，避免内容越界；不同尺寸字体不会被拉伸。

1×1 模拟钟只显示放大的圆形表盘，不显示数字时间、日期和星期。1×1 数字钟只显示时间，不显示日期和星期；竖向格子将主要高度用于时、分。两款单格时钟的设置页已移除日期相关选项，更新后已有实例直接采用新布局，保留时区、配色等仍有效的设置。

两款单格插件在 protobuf 描述中设置 `content_padding: 3`，将宿主留白从每边 12 逻辑像素减到 3。宿主布局和 GPU 内容抓取使用同一留白，其他插件仍使用自己的默认值。

1×4 模拟钟采用左右均衡布局：左侧圆形表盘居中，右侧大号时间与日历居中对齐，宿主每边留白为 6 逻辑像素。各款时钟都有紧凑柔和的文字、刻度、指针投影与细微高光；模拟表盘增加薄表圈和轴帽层次。“立体阴影强度”按实例保存，默认 65%，设为 0 可关闭立体细节。内容仍保持透明，与桌面材质合成。

## 每实例设置

右键插件砖块 → 插件设置。时间制、时区、日期、星期、秒数、字体配色和内容比例按每个实例分别保存；模拟钟可选择跳秒 / 连续扫秒。默认文字跟随桌面主题，可关闭后自定义文字、日期和秒针颜色。

暂停时取消定时订阅并冻结当前时间，恢复时重新读取系统时间。普通刷新每秒一次，模拟扫秒约 30 FPS；缓存未变化时复用预乘 RGBA 内容。

## 验证与对照

独立构建仅运行 Clock 相关检查；在主程序编译部署后运行：

```powershell
./scripts/verify-clock-plugins.ps1
```

验证十一个正式宿主实例的设置隔离、恢复、主题文字、暂停、Release 包导入和更新，再生成正方格 / 长方格的 22 张真实 GPU 预览。设计对照见 `design/CLOCK_PLUGINS_PREVIEW.html`。预览工具的固定 10:08:30 只用于对照；发布插件显示真实时间。

数字钟和模拟钟默认使用宿主 `assets/fonts/SiYuanZhenHei-Heavy/GenShinGothic-Heavy-2.ttf` 外部字体文件，未嵌入 DLL 或 `.cdpkg`。构建脚本自动复制共享字体到程序旁的 `assets/fonts`，无需安装字体。实例设置可选择已安装字体，并选择简体中文或英文；英文使用英文星期与日期格式。字体和语言均按实例保存，旧配置自动使用新的默认值。

## 翻页卡片时钟 2×2、1×4、2×4

ID 为 `com.cyberdesktop.clock.flip.2x2`，发布包为 `flip-2x2.cdpkg`。上下卡片显示小时和分钟，小秒卡位于分钟卡片内右侧，垂直居中，为大数字预留空间；可关闭秒数，不显示日期和星期。默认浅色卡片、12 小时制和 500ms 翻页，可独立设置卡片颜色、数字颜色、阴影强度、字体、语言和 200–900ms 翻页时长。

数字改变时，上半页围绕中线向下折入，再由新数字的下半页向下展开。使用连续透视采样和角度阴影，保持数字上下两半对齐；只有改变的卡片翻动。动画期间约 60 FPS，静止时复用缓存且不请求重绘；隐藏小秒卡后，秒数变化也不触发动画。暂停冻结当前图像，恢复直接显示当前系统时间。独立构建输出五个确定动画阶段的 PNG 到 `build/clock-release/design/flip`。

1×4 和 2×4 分别固定占用一行四列、两行四列，ID 为 `com.cyberdesktop.clock.flip.1x4` / `com.cyberdesktop.clock.flip.2x4`，对应 `flip-1x4.cdpkg` / `flip-2x4.cdpkg`。两款均将时、分卡片横向排列，小秒卡位于分钟卡片内右下方，右边缘与分钟数字的实际右边缘对齐；可关闭秒数，不显示日期和星期。三款翻页时钟默认字体均为 `@zqk-free`，从外部 `assets/fonts/ZQKFreeFont/ZQKfreefont-2.ttf` 加载。字体选择可在 ZQK、思源 Heavy 和安装字体之间切换；恢复默认使用 ZQK。已保存的自选字体保持原值。

翻页、电子、方块点阵和圆形点阵时钟均声明 `content_padding: 4`，外层卡片与频谱使用相同的边界留白。背景圆角统一默认 5 逻辑像素，各实例可在设置中按整数调整为 0–32。内部排版随实际画布自适应；关闭秒数时，数字利用腾出的空间。点阵外沿距背景四边统一 4 逻辑像素，横向和纵向分别均分点间距，圆形点保持正圆；内容统一裁剪到外层圆角轮廓。

绘制底层已接入公共 `sdk/Canvas.h`，共享实际 DPI 目标、透明清屏、帧结束和 RGBA 读取；原有字体、文字基线、阴影、像素字与表盘路径保留。`sdk/Update.h` 统一定时器所有权，`sdk/Environment.h` 提供实例时钟与预览固定时间；没有可见时间变化时不请求重画。翻页的专用字面缓存和运动仍独立保留。

翻页时钟主画布也已迁移至公共 Canvas；保留最多 32 个离屏字面、实际 DPI 的字体缓存和原有透视翻页采样，尺寸/DPI 变化时重建。
