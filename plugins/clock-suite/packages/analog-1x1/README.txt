模拟时钟 1×1 1.0.0

在 CyberDesktop 中导入对应 .cdpkg，在空白区域右键“添加插件…”打开设置插件目录，再点击“添加到桌面”。尺寸表示行×列，实际宽高随网格改变。
右键插件砖块的“插件设置…”修改本实例的时区、秒数、配色和内容比例。
此单格版本只显示放大的表盘。时钟以系统时间为来源，不进行网络校时或访问网络。
插件只提供透明 RGBA 内容，砖面、接缝、悬浮、拖动和涟漪由桌面渲染。

Windows 10/11 x64，C ABI 1，/MT。只需发布此单个 protobuf .cdpkg；私有内容及本说明均已入包。
SDK 辅助代码的 MIT 许可见 licenses/CyberDesktopSDK-MIT.txt。
