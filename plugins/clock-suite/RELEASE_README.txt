CyberDesktop Clock 1.0.0 · Windows 10/11 x64

此目录包含十一个正式插件发布包：数字时钟和模拟时钟各 1×1、1×2、1×4、2×2，以及翻页卡片时钟 2×2、1×4、2×4。
尺寸按行×列，1×4 是横向四格。适配正方格和竖向长方格；模拟表盘保持圆形。

新版本 CyberDesktop 已内置这十一款插件。桌面空白区域右键 → 添加插件 → 设置中的方形分类 → 对应时钟的添加按钮。
另行安装时：桌面设置 → 插件 → 安装插件包，选择一个 .cdpkg。
右键插件砖块 → 插件设置，只修改当前实例。设置随桌面布局保存。
更新已有同 ID 插件时，先停用插件或退出宿主；运行中的 DLL 不会被覆盖。

每个 .cdpkg 都是独立完整的 protobuf 二进制文件，包含插件 DLL、描述、设置定义、使用说明和 SDK 许可。
无 Qt、动态 VC 运行库或插件私有 DLL 依赖。数字/模拟钟默认思源 Heavy，翻页钟默认 ZQK FreeFont；字体使用程序 assets 下的共享文件（未嵌入包），也可选择系统字体；设置支持简体中文和英文。
时间来自系统时钟，可选本地、UTC、自定义 UTC 偏移，支持 12 / 24 小时；不进行联网校时。

目录索引见 catalog.json；所有交付文件 SHA-256 见 SHA256SUMS.txt。
