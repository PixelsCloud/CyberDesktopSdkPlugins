电子像素沙漏 / Pixel Hourglass 1.2.1

固定尺寸：1 行 2 列，矩形布局。左侧为像素沙漏，右侧为点阵倒计时。
另有 1 行 1 列的方形版本：只显示居中的像素沙漏，不显示标题、文字、数字、状态或进度条。
像素沙粒逐步离开上仓，经过细颈下落并在下仓堆积；每帧沙粒总数保持不变。
默认启用物理沙粒：105 颗沙粒由 Box2D 模拟碰撞、滚动和堆积，翻转时跟随容器运动，翻转结束后将原有沙粒重新填充上仓，再开始下一轮碰撞与堆积。
细颈采用计量式出砂以保持倒计时准确，高速翻转另有容器边界保护；不是精确的颗粒流体实验。
关闭“物理沙粒”可恢复经典像素动画；切换模式会重新开始。
默认 30 秒一轮，流完后用 1 秒整体翻转并继续；可关闭循环，作为一次倒计时。
点击左侧沙漏重置，点击右侧计时区暂停或继续；拖动卡片不触发点击。
方形版点击上半部重置，下半部暂停或继续；设置中也不提供文字显示选项。
结束后任意有效点击重新开始。倒计时没有系统通知或响铃。
时长 5–3600 秒；暖金琥珀、薄荷绿、冰蓝三种配色。
昼夜默认跟随桌面主题，可手动固定；可关闭背景或倒计时显示。
像素发光强度、背景圆角及 15/20/30 FPS 均可独立设置，默认圆角 5、20 FPS。
隐藏、全屏或用户暂停时注销定时器；恢复时不追赶休眠经过的时间。
计时位置为临时状态，每次创建从头开始；设置由宿主按实例保存。
只更新插件内容区域，没有后台网络、目录扫描或磁盘写入。

Windows x64 /MT，复用 SDK C ABI 与设置工具，使用系统 Direct2D/DirectWrite/WIC。
所有像素图形由代码绘制，无外部图片、字体、Qt 或私有运行时依赖。
SDK MIT 许可随包附带在 licenses/CyberDesktopSDK-MIT.txt。
Box2D 3.1.1 静态链接，MIT 许可随包附带在 licenses/Box2D-MIT.txt。

沙漏的目标创建、透明帧、DPI、像素读取和 PNG 编码已统一到 `sdk/Canvas.h`；定时器使用 SDK RAII 所有权，单实例仍保留沙粒守恒、翻转、暂停与设置回滚规则。迁移前后 192 组原始 RGBA（含透明模式、1/1.5/2/3 倍 DPI、安全区和行填充）完全一致。
