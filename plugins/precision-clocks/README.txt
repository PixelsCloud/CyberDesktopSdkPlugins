精密钟表三件套 / Precision Clocks 1.0.1
三款独立的 2×2（列×行）原生桌面控件：镂空精密机械钟、翡翠绿潜水表、玫瑰金月相表。
在“桌面控件”中按名称搜索并添加；每次添加创建独立实例，设置和显示互不影响。
独立的精钢绿盘、玫瑰金枕形月相和深色镂空表壳；壳外透明，无矩形底板、顶部标题和外置日期。
整表含表耳、表冠等比居中；在五档 4:5 网格中保持四周留白，不拉伸表盘或铺满砖块。
按实际表壳轮廓计算占位，排除素材自带透明边，左右可见空隙约为内容区域宽度的 5%。

默认每秒八次机械微步，也可选流畅扫秒或整秒跳动。日期、时区、时分秒都跟随宿主系统时间。
镂空款由程序绘制六组齿轮、摆轮、游丝和擒纵叉，PNG 提供带透明孔的固定桥；45 齿轮约 17.3 秒一圈。
摆轮采用便于小尺寸观看的 1.25Hz、±10° 演示速度，固定轴心和游丝外端，不模拟真实机芯频率。
这是定时机械动效，不是完整钟表机构物理仿真，不使用 Box2D 影响走时精度。
绿色款使用实时日期，月末、闰日与午夜切换遵循公历及当前系统时区。
月相款复用现有 sxtwl 天文历库，计算日月视黄经差；用 UTC 和 TT-UT 校正，不将农历日或固定周期当作实时月相。
感谢寿星天文历原作者许剑伟先生，以及 sxtwl_cpp 作者元谷。
依赖来源：https://github.com/yuangu/sxtwl_cpp，仓库固定修订见 third_party/sxtwl/provenance.json。

设置提供秒针、机壳、细节、动画及减少动态开关；隐藏机壳后只显示圆形表盘。
关闭动画或减少动态后，装饰机构停止，时钟继续每秒更新准确读数。
隐藏时释放所有计时器，恢复及系统跳时直接定位当前时间，不补播隐藏期间的动画。
共享 SDK 的后台图片解码、局部刷新、原生路径和离屏缓存；表盘直接解码到实际 DPI 的最终像素尺寸。
只在素材、尺寸或 DPI 改变时更新静态表盘；旋转部件独立绘制，不转动整张静态图。

PNG 素材按三张已确认设计拆分，来源、哈希见各包 assets/provenance.json；活动指针、月相及齿轮不烘焙在表盘上。
每张源素材为 1254×1254 透明 PNG，运行时直接预滤波解码到实际显示像素，兼顾最大网格与高 DPI。
缺失素材时仍提供程序绘制的可读表盘。图片、概念图、测试和演示不作为额外运行入口发布。
专项构建验证：scripts/build-precision-clocks.ps1 -Jobs 10，可加 -Frames 导出实际绘制帧。
统一发布：scripts/build-all.ps1 -Jobs 10；唯一运行目录 build/dist。
