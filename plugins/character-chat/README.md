# 虚拟人物聊天插件

正式原生插件提供 6×4、4×5、6×6（宽×高格子）布局。四种成年女性角色模板可编辑、复制、恢复默认；当前共用夏晴示范视觉资源。输入支持中文 IME、Enter 发送和 Shift+Enter 换行。

默认离线运行。管理窗口可填写自己的 DeepSeek Key、发现模型、设置请求额度并切换真实模式。Key 保存在 Windows 凭据管理器，SQLite 只保存引用。离线与真实会话、草稿、分支和素材发送记录分别保存。每次发送最多一个生成 POST；没有自动重试、补格式或分类调用。重试、重新生成与真实预览均由用户明确触发，账本记录各自来源。

图片立绘支持八种情绪、默认/挥手/抱臂姿态、三种场景和局部过渡；Live2D 可选择 Mao/Haru、30/60 FPS，并预览模型实际存在的表情和动作，再保存语义绑定。四个模板共用视觉资源的情况在界面中说明，未宣称具备四套独立人物美术。

设置页的表情与动作从当前角色图片包或当前 Live2D 模型动态生成，不再共享固定列表。支持自定义图片表情与姿态名称，以及模型所有真实动作组；已打开的设置页随切换更新。人物演出、模型目录和帧率按角色保存，手动预览按角色与图片包/模型指纹保存，切回后恢复，失效选择回到自动。Live2D 手动预览使用实际 ID；对话自动演出继续使用经用户确认的语义绑定。SDK 可选服务 `ui.settings_choices` 更新单实例声明字段的选项与作用域，不改变原有 ABI。

同一轮回复的多条对白与旁白自动一起展示，流式片段到达后直接追加，不需要点击下一句、翻页或略过。长内容复用 CyberCanvas ScrollView，支持滚轮和拖动滚动条，输入框保持固定。素材请求不占正文位置，成功发送的附件直接显示缩略图；筛选、冷却、解锁等内部说明只在管理页面保留，实际连接或资源加载错误仍可见。保留旧存档的阅读游标格式，完整回复送达时自动推进，不再限制正文显示。

角色、提示词、历史、分支、播放位置、固定记忆及确认后的摘要和偏好由 SQLite 保存。提示词和资源版本不可变；修改设定、重生成和预览建立分支，保留原历史。模型只能提议事件或偏好，本地规则与用户确认决定是否应用。

人物/媒体目录和 ZIP 可导入、编辑条件及导出。外部图片解码、ZIP 检查和视频探测运行在受监督工作进程，验证路径、数量、长度、哈希和实际内容。坏包保留现有角色与会话，并给出可读提示。附件固定到已提交的资源版本，重开不重新随机选择。视频需要用户点击后才交给 Player 播放。

所有人物图片均为随插件发布的独立文件，不嵌入程序。`characters.toml` 配置角色姓名、年龄、开场白、提示词及素材目录；每个素材目录中的 `character.toml` 配置情绪映射、姿态图、场景、媒体条件和本地关系规则，文件内有中文注释。可以替换图片或修改路径，再在管理窗口点击“重新加载 TOML”。哈希、文件大小、图片尺寸和视频参数由隔离工作进程自动检测，不需要手工维护。

配置更新接续到新版本的分支，旧消息的附件始终引用原素材；删除当前场景时，新分支选择仍存在的场景，旧分支不变。离线和 DeepSeek 通道分别记住已应用的配置版本，切换通道不调用 API。未变动的配置不会覆盖管理窗口中的设定，也不会强行切走用户重新选择的历史分支。导出 ZIP 附带可编辑 TOML，修改 TOML 或替换 ZIP 内图片后可重新导入；旧 JSON 人物包仍兼容。

将自建素材目录放在 `assets` 下。增量发布会保留修改后的 TOML、图片、视频及新增图片，并独立记录发行默认值，以便后续多次升级仍能识别用户定制。正式插件目录仅发布 TOML 配置及独立资源，旧 JSON 示例保留在源码中用于兼容性测试；不可变缓存中的 JSON 是内部存档格式。

## 构建与验证

从仓库根目录运行，复用既有编译目录，限制为最多十个逻辑核心及十个并行作业：

```powershell
./build/tools/powershell/pwsh.exe -NoProfile -File scripts/build-character-chat.ps1 -Jobs 10
```

日常仅构建受影响目标可传 `-Targets` 与 `-BuildOnly`。工具和报告保留在 `build/relwithdebinfo` 与其固定 `Testing/character-chat` 下。默认专项不访问付费 API、不发布到 dist。正式统一构建使用 `scripts/build-all.ps1 -Jobs 10`，唯一运行目录为 `build/dist`。

生产服务使用 CPR/libcurl、nlohmann/json、SQLite、miniz、toml++ 和既有 Image/Player/Live2D 运行库；测试程序、故障工作进程、凭据、报告和截图不进入发布目录。

## 验收证据的边界

实际 DeepSeek 百次批次、真实微软拼音、原生 DLL 集成、硬件 GPU 合成、长时间变异及耐久分别报告，不互相替代。`tools/OfflineDemo.cpp` 是保留的开发原型，其测试素材路径和内存状态不代表正式插件行为。

`cd_character_chat_native_benchmark` 测实际 NativePlugin、不同 DPI 绘制、输入反馈、完整流片段到卡片绘制，以及普通 Live2D 与聊天合成的 GPU 对照。流测试重放已录制回复并按原 API 返回的输出 token 数分段定速，不声称拥有真实 token 边界，也不发出 HTTP。`--smoke` 仅验证测试工具，不能产生正式性能通过结论；正式测试拒绝与编译、模糊测试或耐久工具同时运行。

人工质量评审由 `scripts/review-character-chat-quality.py` 生成离线评分页。没有人工评分、规定时长稳定性及正式包使用证据时，不将 V1 标记为全部验收完成。
