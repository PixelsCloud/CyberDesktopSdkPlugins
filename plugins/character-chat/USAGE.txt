虚拟人物聊天

在插件列表添加本插件，可选 6×4、4×5、6×6（宽×高）。点击输入框打字，Enter 发送，Shift+Enter 换行。输入法组合中的 Enter 只确认输入。生成时可停止；一轮回复中的多条对白和旁白自动一起显示，长内容可用滚轮或拖动滚动条阅读，无需点击下一句。未发送的素材不会在聊天区显示内部筛选提示，成功发送的图片直接显示为缩略图。

输入框与发送按钮保持等高对齐，提示文字和单行输入垂直居中。多行文字在输入框内滚动，不会撑高卡片底部或挤动发送按钮。

默认离线演示不调用 API。切换 DeepSeek 前，点击齿轮进入“连接设置”，填写自己的官方 DeepSeek API Key、测试连接并选择模型。Key 保存在 Windows 凭据管理器。读取模型列表不生成对话；发送、显式重试、重新生成和真实预览会计入额度，不会自动重试。用量未知时保留保守预留。

管理窗口可以编辑、复制和归档角色，恢复默认提示词，选择场景、回复长度、媒体和动作开关，编辑固定记忆及已确认摘要。模型给出的偏好、摘要和剧情提议不会自动修改设置。剧情解锁需要符合本地条件，并按界面要求确认。

四个默认模板均为成年女性，共用夏晴示范视觉包。图片模式包含八种情绪、挥手/抱臂及三个场景。Live2D 示例为 Mao、Haru；实际表情和动作请在管理页预览后自行绑定，未绑定的项目保持默认。

插件设置中的表情和动作列表随当前角色、素材版本及 Live2D 模型自动更新，已打开的设置窗口也会同步。图片列表读取 character.toml 中声明的情绪、表情图片和 pose 用途图片；自定义动作可使用 pose_salute 等资源 id。未映射到情绪的表情图片以图片 id 显示。Live2D 列出模型自带的真实表情名称和全部动作组，可直接手动预览；自动跟随聊天仍使用管理页中确认的语义绑定。

各角色分别记住图片/Live2D、模型目录和帧率；表情、动作选择按角色及具体图片包/模型指纹分别保存。切回原角色或立绘会恢复对应选择，资源删除选项后自动回到“跟随对话”。这些选择随桌面存档保存，其他聊天卡片不受影响。

人物图片均作为独立 PNG/JPEG/WebP 文件发布，不嵌入 EXE 或 DLL。编辑插件根目录 characters.toml，可修改角色名称、年龄、开场白、提示词和各角色的素材目录。编辑对应目录中的 character.toml，可修改情绪到图片的映射、动作图、场景、可发送图片/视频和解锁条件；每个文件开头均有中文说明。

直接替换图片即可，不需要填写哈希、文件大小、尺寸和视频参数。保存后在管理窗口点击“重新加载 TOML”，或重启 Desktop；切换角色时会读取该角色的素材。新增角色可复制一段 [[characters]] 并使用独立 id；不同角色可指定不同的 pack 目录。以后发布升级会保留用户修改过的 TOML 和 assets 目录中的图片、视频，请将自建素材目录放在 assets 下。

配置更新会建立新的人物/素材版本，并接续到新的聊天分支；旧聊天和已发送附件保留原版本。未变动的 TOML 不会覆盖管理窗口中保存的设定。坏配置、缺文件和损坏图片会提示错误，重新加载失败时继续保留当前可用人物。图片模式的情绪映射与 Live2D 的模型动作绑定分别配置。

人物页可导入/导出完整人物目录或 ZIP；素材页导入只更新发图资源，支持批量编辑条件和导出。坏包、缺图和超限内容会提示错误并保留已有记录。重新导入相同内容可修复缺失文件；不同内容会建立新版本，不替换旧附件。

素材按标签、解锁、冷却和次数筛选，没有符合条件的素材时不会假装发送。视频只有点击播放后才交给同目录 Player。离线演示和 DeepSeek 分别保存历史、草稿、解锁及发送次数。

重新生成和真实预览使用独立分支，原回复与附件保留。预览可返回原分支或保留为聊天分支；已产生的调用用量仍计入账本。删除卡片或归档角色不会自动删除聊天历史。
