# Production widgets

Sixteen Windows x64 C ABI 1 plugins: spectrum 1×4 / 1×6 / 1×8, radial spectrum 2×2, round LED matrix 1×4 / 1×6 / 1×8, square LED matrix 1×4 / 1×6 / 1×8, music controls 1×4 / 2×2 / 2×4, input statistics 1×4, album 2×4 and calendar 2×4. Fixed footprints adapt to square or rectangular desktop cells. All have per-instance settings and Simplified Chinese / English settings pages. Text views use external selectable fonts. They use the host's incremental plugin rendering path.

Outer backgrounds use the spectrum's spacing: the host reserves 4 logical pixels per side, and each face occupies (1, 1, width-3, height-4) inside that canvas. All sixteen plugins expose an integer background corner radius, default 5 and adjustable from 0 to 32 logical pixels; 0 gives square corners. The album's photo clipping follows the same radius. Spectra only draw a background when their optional plate is enabled; music controls and input statistics default to a dark card.

Run `./plugins/widget-suite/build-widgets.ps1 -Jobs 18` against the deployed SDK to build, run the focused tests, export 48 real-render designs and create sixteen self-contained `.cdpkg` files in `build/widget-release/artifacts`. An optional `-PhotoDirectory` supplies a real photo for preview export. Source spectrum design board: `design/widgets/widgets-v1.png`; native designs: `assets/designs/music-player/` and `assets/designs/input-stats/`.

Input statistics declare `INPUT_STATS` and use the optional 80-byte `CdInputStatsHostApi` extension. One background host Raw Input receiver counts physical key presses (excluding autorepeat) and the five mouse-button DOWN transitions (double clicks count twice; move/wheel are excluded). It aggregates all keyboards/mice in the current desktop session. Key identities are held only transiently for repeat suppression, never persisted or exposed. Today resets at local midnight, totals survive restart, and session counters begin when recording is first enabled in the process. Aggregate counts are atomically saved in the application's local AppData `input-stats.json` at most every ten seconds and on normal exit. Recording continues during fullscreen/display pause; hidden instances unsubscribe from display updates, not from recording. The plugin uses no polling timer and requests a local redraw only when displayed counts change, at most once per second. The host cannot recover input from periods when it was not running. Native mock preview uses simulated counts.

Music controls use the optional `CdMediaHostApi` extension and declare `MEDIA_CONTROL`. A process-wide host reader uses Microsoft's C++/WinRT to consume GSMTC sessions on Windows 10 1809+ / Windows 11. Player settings select the current system session or match QQ Music, NetEase Music, Kugou or Spotify by source ID. Registration and capabilities depend on the installed client; QQ Music 22.76 has been verified locally. Metadata and cover updates are event-driven and cached; asynchronous OS requests, bounded cover decoding and commands run on the host worker. With no subscriptions, the reader sleeps; hidden instances unsubscribe. Music artwork is clipped to a circular label inside a grooved vinyl record, rotating once every 20 seconds while playing at 30 fps. Pausing holds the current angle and returns the shared timer to one second; idle records request no continuous redraws. Missing artwork uses a rotating label, and covers stay cached at the actual render DPI. Commands bind to the last delivered session and check current capabilities before execution. Missing players show a stationary vinyl placeholder, and unavailable commands are disabled. The SDK CLI/preview supplies synthetic media without controlling real players.

Music uses 63 logarithmic FFT bands from the host, a 12 ms attack, configurable 40–600 ms release (default 160), 180 ms peak hold and a separate peak fall. Each view samples the same spectrum. Continuous/radial spectra remain transparent by default. LED matrices default to a dark card with green round dots or yellow squares; the plate can be disabled independently. No synthetic animation is mixed into live music. Stale audio decays to zero and stable silence requests no redraw. The preview host's demo data is separate from desktop WASAPI capture.

LED matrices offer 6–24 rows (default 9), 0–100 glow strength (default 70), base/top colors, peak indicators and the shared card settings. Rows determine dot size and equal horizontal/vertical spacing; columns fit the available width without a fixed column limit. Dot envelopes keep 4 px vertical margins inside the face and are centered horizontally with at least 4 px margins; column rounding adds less than half a cell on each side. Circles remain round. Downsampling retains narrow FFT peaks. Fractional top-dot opacity keeps small signal changes visible. Static background grids and per-row light sprites are cached per instance, recreated only for geometry/presentation changes; audio frames reuse them. All six matrix packages include renderer-generated previews.

The existing FFT/band mapper was compared with `C:/source/rhythm_master` revision `a16510bdd32916b76aaabec79f8a18995f07b280`: `src/audio_analysis/analyzer.cpp`, `detail/fft.*`, `detail/band_map.*`, and `src/runtime/audio_spectrum.cpp`. Both use 4096 Hann FFT, logarithmic bands, peak/RMS aggregation and bounded adaptive gain. No new source was copied from that repository. The desktop removes a redundant host release filter, combines stereo channel energy after FFT to prevent antiphase cancellation, and feeds zero samples when loopback is silent.

Album directory defaults to the Windows Pictures known folder, honoring redirected folders. Enumeration and WIC decoding run on an instance-owned worker; the UI receives complete immutable bitmaps. Enumeration is bounded to 50,000 entries, recursive depth four. Decode is bounded to 100 million source pixels and 1,024 px output on the longest edge. Corrupt images are skipped. EXIF orientation is respected. Directory refresh is once per minute; transitions alone request animation frames. PNG/JPEG/BMP/GIF/TIFF use Windows codecs; WebP/HEIC need installed WIC codecs. GIF uses its first frame. No photos are bundled or fetched from the network.

Calendar highlights the local current day, offers month arrows and a double-click return to today, supports Monday/Sunday start and optional adjacent month days. Only actual date/month/settings changes redraw the calendar.
