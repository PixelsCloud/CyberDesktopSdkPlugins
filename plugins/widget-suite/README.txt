CyberDesktop Widgets 1.0.0

机械音乐控制为独立插件，支持 4×1 / 2×2 / 4×2（列×行）。
在控件列表搜索“机械”后添加；本套件原有音乐控制保持原样，没有外观切换设置。

音乐频谱 1x4 / 1x6 / 1x8，环形频谱 2x2；
圆点阵频谱、方点阵频谱各有 1x4 / 1x6 / 1x8；音乐控制 1x4 / 2x2 / 2x4；
键鼠计数 1x4；相册 2x4 / 日历 2x4，共 16 个插件。
Windows x64，C ABI 1，/MT，无 Qt 依赖。每个实例独立设置，简体中文和英文。
键鼠计数：本体后台统一统计，键盘长按不重复，五个鼠标按钮按下计数，双击算两次；
移动、滚轮不计。今日按本地午夜归零，累计计数本地保存并在重启后恢复；
全屏时仍统计，多个实例共用计数。仅统计本体运行期间，插件最多每秒局部刷新一次。
字体由宿主 assets/fonts 提供，默认思源真黑 Heavy，可在实例设置中选择。

音乐：WASAPI 桌面音频，4096 点 Hann FFT，63 对数频带（20Hz–16kHz）；
快速起音、可调回落、独立峰值保持。停止音乐后回归零，静止不重绘。
音乐控制：本体共享媒体会话服务，显示真实歌曲、歌手、封面和进度；
支持播放器提供的播放/暂停、上一首、下一首和进度定位能力。可自动选择或固定播放器。
Windows 10 1809+ / Windows 11，播放器必须注册系统媒体会话。未开放的按钮自动禁用。
读取、解码封面及控制命令均在后台；唱片封面播放时以 30 FPS 缓慢旋转（20 秒一圈），暂停保持角度；隐藏时停止动画。
黑胶外圈、细密纹路搭配圆形专辑封面，缺少封面时显示唱片标签。播放期间仅局部刷新，空闲不连续重绘。
点阵：默认暗色底板，圆点绿色、方点黄色；行数决定点阵大小，横纵间距相同，
列数随宽度自动调整，整体水平居中；可调整点阵行数、
辉光、底部/顶部颜色、峰值、背景和整数圆角（默认 5）。网格和发光点纹理缓存复用。
相册：默认系统 Pictures 目录，可浏览目录，支持子目录、裁切/完整显示，
切换间隔、淡入时长、圆角和计数。双击下一张。文件在后台扫描和解码；
JPEG/PNG/BMP/GIF/TIFF 使用 Windows WIC，WebP/HEIC 取决于安装的解码器。
GIF 显示首帧，EXIF 旋转按方向显示。目录每分钟重新扫描。
日历：按本地日期突出今日，左右箭头切换月份，双击返回当前月。
支持周一/周日起始、前后月日期、卡片颜色、今日颜色。

All settings are per instance. Images are user-owned external data, not bundled
in the plugin package. The album performs no network requests.

主画布、实际 DPI、透明抗锯齿、预乘读回和 PNG 导出统一使用 CyberCanvas；计时器由 SDK Timer 事务性管理，专用排版、视图、后台数据/图片与实例状态保持原有行为。
