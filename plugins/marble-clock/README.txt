滚珠轨道时钟 1.2.0

提供 6×2、4×2（宽×高）两种独立布局；主程序桌面控件搜索“滚珠轨道”即可添加。
采用精密剖面式机械外观：缎面钢机壳、黄铜齿轮、滚筒字窗和抛光钢珠使用独立 PNG。
4×2 与 6×2 分别制作机壳，包内仅附对应尺寸；按可见轮廓和真实轴心定位，螺丝与运动零件保持等比。
机壳按实际物理像素宽度分档解码，字轮数字、轨道、翻板和连杆保留原生 DPI 绘制。
素材通过现有共享后台解码器加载，同实例重复钢珠复用纹理；载入完成后才刷新静态缓存。
送料轮按真实发球事件拨动；齿轮与定长连杆由实际翻板角度计算，回收皮带在插件物理时间中运行。
数字采用独立滚筒窗口，走秒时短暂滚动；减少动态和跳时直接显示准确读数，不播放过期过渡。
固定 4:5 网格下保留六位滚筒与完整物理结构，四周留出短边 4.5% 的透明间隙。
不以普通数字标题条替代滚筒，也不额外添加顶部标题栏、底部计数或储槽标签。
左上角不显示名称、铭牌及其固定螺钉，只保留机壳本身的金属边框。
每秒投一颗真实 Box2D 滚珠。整分钟时，翻板通过带角度限位的电机转轴开启；球沿重力斜面滚落回收。
卸料口伸入集球仓，仓底略向左倾斜；配合低摩擦滚珠将来球导入仓内，避免连续走秒时堵回上层轨道。
时分秒始终以系统时间为准。仓上计数表示本分钟的投珠刻度，仓内球数因在途、回收与交互可能不同。
开仓期间新一秒投珠暂存，翻板闭合后按间隔释放；队列最多 8 颗，不补算隐藏和系统跳时的离线物理。

操作：点击左上投珠器补一颗试验球；点击或双击金色转轴演示开仓；拖动滚珠后松手可继续真实碰撞。
设置：深色、浅色或跟随系统主题；背景开关；启用滚珠动画；减少动态。
隐藏时停止订阅计时器并释放抓取，恢复时直接重建当前分钟的稳定球堆，不重播已过去的动画。
减少动态或关闭动画后依旧每秒更新数字和静态球堆。

实例最多 72 颗球，加一片动态翻板；静态轨道按实际 DPI 缓存，只有所属插件申请局部刷新。
正常球从回收口移除；异常堵塞超过 8 秒才启用回收兜底。时间、计数不受堵塞影响。
静态图片与动效分镜在 design/marble-track-clock.*；实际 C++ 渲染预览与测试输出位于编译目录 Testing/marble-clock。
专项验证：PowerShell 7 执行 scripts/build-marble-clock.ps1 -Jobs 10，可加 -Performance。
统一发布：scripts/build-all.ps1 -Jobs 10，唯一运行目录 build/dist。

基于 CyberDesktop SDK / CyberCanvas / Box2D，相关 MIT 许可随包附带。
PNG 素材来源与哈希见 assets/NOTICE.txt、assets/provenance.json；素材不会改变滚珠碰撞形状和轨道几何。
