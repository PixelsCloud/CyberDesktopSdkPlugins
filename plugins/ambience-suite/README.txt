桌面生活插件 — Windows x64 /MT, C ABI 1（盆栽 1.0.1，白噪音 1.0.3）
卡通盆栽 1×1 / 2×2 / 2×4，白噪音 1×2 / 2×4。
卡通盆栽：绿萝、多肉、小雏菊。默认显示成株，轻养成约七天长成；点击花盆浇水，点击叶片轻摆。
浇水每小时最多一次成长增益，离线按时间成长；植物不会因缺水死亡。生长状态按实例保存。
小尺寸可透明观赏，大尺寸显示名称和浇水按钮，2×4 可显示三盆小花园。
动画默认 0.75 倍、20 FPS，仅刷新自身卡片；隐藏停表，恢复不追赶动画。
轻摆与浇水反馈共用 CyberCanvas 动画模块；关闭常驻动画后，浇水仍短暂播放反馈，结束后静止盆栽停表。
白噪音：雨、海浪、溪流、森林鸟鸣、壁炉、风。通过宿主 audio.ambient 服务共享播放引擎。
白噪音使用六张生成的透明 PNG 插画，每张左右分别为昼、夜版本；雨云、海浪、溪流、森林、壁炉与风草均为实际素材。
素材、原始提示词及哈希在插件 assets/noise 内，WIC 只解码一次并缓存，以平滑缩放合成真实透明边缘。
1×2 点击图画或声音名称轮换六种声音，下方播放按钮与主音量滑条独立操作。
默认停止、主音量 25%，点击播放；混音最多四路。点击滑条调整音量，拖动卡片不会误触控件。
播放时有音量的插画轻微缩放和明暗呼吸，可关闭或调整速度/帧率；暂停、静音时停止呼吸与不必要的重绘。
混音面板“更多”切到溪流和风声。定时可设 0—240 分钟，0 不限时，结束前十秒渐弱。
声音在画面隐藏、全屏时继续播放和计时，删除最后一个关联实例或退出程序时停止。
播放与声音素材由新版宿主提供；SDK 无音频服务的预览环境只展示静态控件，不自动播放。
所有配置按实例保存；播放状态不在重启后自动恢复。简体中文内容，界面可切换语言设置。
声音来源、署名与许可随宿主 assets/ambient 提供；使用 miniaudio 播放。

多个白噪音卡片可选择同一共享声音组，共用音量与播放状态；默认各自独立播放。
缓动使用 Tweeny 3.2.1，MIT 许可随插件 licenses/Tweeny-MIT.txt 分发。

白噪音总音量和分轨音量支持连续拖动；拖出卡片时保持调节并限制在 0-100%，松开、隐藏或丢失捕获后结束。滑块拖动不会移动卡片。旧宿主保留点击设置音量。

白噪音控件使用 CyberCanvas 0.5，绘制、命中、步进和反馈共用描述；图标使用宿主的 Lucide 公共入口，旧宿主使用文字后备。
