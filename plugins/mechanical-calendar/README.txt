机械月历 / Mechanical Calendar 1.0.2

独立机械系列插件，固定 4×2（宽×高），不覆盖原版日历或迁移原版设置。
拉丝钢机框、六个年月字轮、金属导航按钮、深色日期格及日期格方框当天标记。
日历显示真实本地日期，按每月实际天数自动生成 4、5、6 周；支持闰年和跨年。
工作日、周末、日期格底色和今天强调色可独立设置，支持字体、语言、周首和相邻月份日期。
左右按钮切换月份，双击日历非按钮区域返回本月；拖动不触发按钮。
翻月时仅改变字轮中的数字，短暂滚动 180 毫秒；开启“减少动态”可直接切换。
浏览月份偏移保存为当前实例状态，其他设置由宿主逐实例保存；不影响其他月历实例。
日期变化时更新当前插件；平时不请求重复画面，隐藏时停止计时器，恢复时重新读取日期。
素材后台解码，静态材质和文字按真实 DPI 缓存，字轮动画只刷新当前插件区域。
年月与日期均实时绘制，素材内没有固定的示例日期。
导航使用 SDK ui.icons 接入 CyberGlass 的 Lucide 图标；旧宿主和独立预览无此服务时显示“上月／下月”。
Windows x64 /MT。插件不链接 Qt，不新增私有运行库或外部字体文件。
许可位于 licenses，素材来源位于 assets/provenance.json 和 assets/NOTICE.txt。
