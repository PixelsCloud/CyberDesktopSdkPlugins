机械翻牌招牌 4×1 / Mechanical Split-flap Sign 1.1.0

采用已确认的薄型异形钢制机壳、黄铜传动轴和十二格黑色翻牌，四周保留桌面间隙。
仅提供 4×1（列×行）；原有插件 ID 保留为兼容标识，不改变实例身份。
旧 6×1 / 6×2 布局由宿主迁移为 4×1，保留自定义文字、分页、速度和动画设置。

文字使用 DirectWrite 按实际 DPI 绘制；钢制机框、字牌材质和传动机构使用原始 PNG。
每格上下半牌分层翻转，逐格启动，落位后轻微回弹；传动组件保留原图材质。
中英文、组合音标、UTF-16 代理对及 emoji 使用 Windows ICU 按完整字符分页。
点击触发一次翻牌，连续点击合并为一次后续动作，修改文字保留最后一份内容。
默认静置五秒巡检；间隔 0 时仅点击翻牌，可调速度和减少动态效果。
静置不持续刷帧；隐藏时停止计时，恢复后不补播隐藏时间。
关闭动画或减少动态时立即显示最终文字，手动点击仍可直接切换下一页。

原始 PNG 按目标尺寸和实际 DPI 在后台解码；保留上一份纹理直到新尺寸准备完成。
机壳及圆形紧固件始终等比缩放，不随砖块宽高比拉伸。
素材源、哈希及许可见 assets/provenance.json、assets/NOTICE.txt 与 licenses。
概念图不随运行包发布，控件目录中的 preview.png 为实际原生绘制截图。

专项构建与验证：scripts/build-mechanical-objects.ps1 -Jobs 10 -Panels
统一发布入口：scripts/build-all.ps1 -Jobs 10；唯一运行目录：build/dist。
