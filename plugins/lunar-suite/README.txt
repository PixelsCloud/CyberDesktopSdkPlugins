农历 1.0.0 — Windows x64 /MT, native C ABI 1
1×2 今日农历条；2×2 日日历；4×4 双历月历。Microsoft YaHei 文字，按实际 DPI 绘制。
离线农历支持 1900—2100 年，算法使用 sxtwl_cpp（寿星天文历），感谢原作者许剑伟与元谷。
显示农历月日、闰月、传统节日及二十四节气。节日不等于法定放假安排，本版没有调休数据。
年月箭头翻月，点击标题或双击回到今天；大月历支持选择日期。拖动不触发点击。
跟随主题/白天/黑夜、透明背景、周起始日、相邻月份及圆角设置按实例保存。
英文模式提供英文星期和周标题；农历、传统节日与节气保留简体中文。
每秒仅检查是否跨日，日期和配置不变时不请求重绘；隐藏停表，恢复检查日期变化。
选中的日期会保存；跟随今天时跨日自动更新。日期按系统本地公历日解释，农历算法采用中国历法。
第三方源码及修订记录见 provenance.json；许可见 licenses/。
