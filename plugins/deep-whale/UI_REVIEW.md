# Deep鲸字体、图标、布局与功能 review

范围：Deep鲸 35 类、75 个独立布局。以原生宿主渲染帧、实际功能区域、Pixels/机械功能基准及源码为依据；不把人物或整个异形组件的中心强行当作功能面板的中心。

## 结论与本轮修正

公共 TextStyle 的默认垂直对齐本来就是 Center。普通标签已经使用可见墨迹居中，不能将所有偏移归因于未设置垂直居中；本轮将对齐属性显式化，并新增实际像素边界验证。重点修正区域登记、字号稳定性、长文本和控件逻辑。

| 优先级 | 问题 | 修正与定位 |
|---|---|---|
| P1 | 长歌名、演唱者被整体缩成很小的字 | Skin::caption 使用 DirectWrite 省略，保留可读字号；PlayerRenderer、三尺寸区域登记 |
| P1 | 相册按钮压在照片上；counter设置无效，双击沿用旧通用布局 | 三个按钮移动到底部面板，接通计数，点击命中使用鲸鱼照片区域；UtilityRenderers、widget/Instance |
| P1 | 天气预报使用摄氏原值、风速固定m/s；当前天气图标根本没有区域 | 统一所有温度/风速换算，三尺寸补icon区域；WeatherRenderer与skin.json |
| P1 | 番茄钟相同数字无法区分专注和休息，未呈现完成次数 | 补阶段行与完成次数，休息比例选择break_minutes；UtilityRenderers |

## 后续功能修正

- LCD 核心新增显式私有字体入口，分别使用包内 Bree Serif 与共享霞鹜文楷，保留系统字体自定义入口。专项用不存在的系统字体名验证中英文实际像素变化，不依赖电脑安装字体。
- 风铃改用成熟 toys / Box2D 模型的六零件布局：铃身、尾片独立约束与碰撞，独立风场、双击拨动、按旋转后完整尺寸限制拖动；原图拆成等比 ROI，补吊线。
- 盆栽复用 ambience 的叶形与生长算法，三品种、三阶段、花园、信息和实际花盆/按钮浇水接通。人物与珐琅盆保持原比例，叶片独立摆动，使用原素材区域及非矩形前景遮罩组织遮挡。
- 白噪音紧凑版轮换六声源；大版分两页控制六轨。实际总播放、主音量、定时与音轨推子共用绘制和命中区域，保留成熟混音、四轨上限、分组与恢复机制。
- 十种频谱布局复用当前 Pixels 音频订阅及运动调度；补颜色、亮度、辉光、减少动态与环形峰值。
- 精密表指针颜色、农历语言/文字与强调色、月历中间翻月帧、文字翻牌上下叶片/背景、玻璃与砂粒共同翻转、倒数日目标日期/每年提示均接入实际绘制。
- 番茄钟增加独立进度区；基础时钟的布局、内容大小、立体强度和翻页/LCD 背景设置接入；输入统计与相册改用宿主单调时间；磁带轮毂读取播放角度。

## 节拍物理运动补充修正

用户实机反馈 4×2、6×2 弹跳不足且有顿挫。此前静态布局、帧变化和交互验证没有测量起跳速度与连续性，未覆盖此问题。

- 节拍动画按用户确认保留 33ms 调度，FFT 保持 30Hz；显示使用 Box2D 固定步长插值，不裁去正常延迟帧的模拟时间。
- 固定冲量改为按球质量、容器高度和节拍强度计算有上限的起跳速度；避免不同球径起跳差异及连续重拍无限叠加。
- 托板短行程与发射冲量协调，回位加入微小误差阈值，避免静音后持续微动。
- BeatScene 为真实运行与专项验证共用的 Box2D 场景。新增两尺寸、六种球数、60Hz/30Hz/抖动帧间隔共 36 组专项验证，测量真实跳高、FFT 节拍次数、连续运动帧、边界和静音恢复。另检查三种球径单次起跳速度；原生 ABI 验证限制每实例一个 33ms 动画定时器。

## 用户确认后的节拍托台与 Dock 修正

- 用户要求节拍组件保留 33ms 刷新。两尺寸底部的玻璃直杆改为三瓣珍珠贝壳托台，碰撞表面也改为对应的三段圆角贝唇；重拍采用短促抬升、缓慢回落的行程，专项验证必须实测托台至少 6px 的逻辑位移。
- Dock 的问题是新增图标时宽度变化触发整张外壳重新解码，旧纹理尺寸不匹配期间完全不绘制，因而中框和两端一起闪失。现在按实际高度和 DPI 缓存左端、右端、中间纹理；宽度变化仅重组缓存，不解码、不排后台队列。高度或 DPI 更新期间也保持完整外壳，各装饰按原比例临时采样，后台新素材完成后替换。
- 补充 30 个连续宽度变化的专项验证，逐帧检查不透明图标通道，断言素材解码次数不增加；保留像素主题图标区域高度对照。


## 原始格子文字与多实例性能复核（2026-10-26）

- 覆盖 catalog 全部 75 个布局。以 80×100px/格核对，不用放大缩略图代替实际尺寸；同时检查 112px 格子、150% DPI，以及专项原生尺寸/DPI 矩阵。
- 功能文字以 12–14 逻辑像素为基准，主读数优先 18–24px；月历日期 14px、星期 12px。仪表盘把标题与读数移至中央，取消底部两个极小文字行。文字按实际绘制变换换算，不把世界坐标的字号误当屏幕字号。
- 小组件的信息取舍：磁盘 2×1 只显示盘符、占用率与容量条；倒数日去掉目标日期提示；农历 2×1 保留公历日、农历月与日；2×2 保留年月、日、星期与农历。播放器小尺寸去掉演唱者小字，扩大歌曲标题。白噪音扩大声源名称区，无定时器时用公共 timer 图标，长时限显示小时。相册扩大计数区，沙漏为浅金色默认倒计时增加深蓝读数窗（保留自选颜色），输入统计图标提升至 12px。空气质量去掉更新提示，天气去掉极小状态提示；网络小尺寸上下排列速率并使用 KB/s、MB/s、GB/s。时钟放不下日期时优先完整时间。
- 长标题使用省略，避免缩成细线。小于 9px 可见高度的提示区不绘制；这不是用全局加字号代替重新排版，主要功能区另行重排。公开 SVG 图标入口及原有命中区保留。
- 性能热点是六个点阵频谱：原来每帧逐珠创建渐变/描边资源。现在按实际显示密度构建珠点精灵及未点亮底层，只绘制亮珠与峰值；颜色、形状、亮度、光晕、目标和 DPI 变化均重建缓存。柱状频谱每帧复用一个画刷及一个峰值几何。
- 共享 Skin 的人物、底图、外框按实际像素大小缓存背景/前景合成层；资源变化、尺寸/DPI 和渲染目标改变时失效。图片自身定时器就绪的回调也先使合成层失效，避免首次缺图被永久缓存。未更改物理组件 33ms 刷新要求。
- HostVerify 新增每布局 12 次真实适配器强制重绘测量，覆盖原始格子、112px/150% DPI 和满幅频谱，并验证满幅音频确实改变频谱图像。测量排除首次文件解码和 PNG IO；总耗时用于同机回归对比，不等同实际桌面 FPS。
- 初轮同机 75 布局强制重绘：原始格子 177.83→45.09ms，112px/150% DPI 203.15→75.45ms；优化后满幅频谱 84.61ms。最终数据以本次 Testing/deep-whale/host-result.json 为准，逐项与 readability-baseline.json 对照。


## GPU 渲染通路复核（2026-10-26）

此前 76ms 是强制全部 75 个组件重新生成内容的专项结果，不是常规一帧的 FPS。复核发现架构开销仍然过高：普通原生组件使用 WIC 软件目标，结束后拷贝并重排 RGBA，再由宿主转换为 BGRA 上传；点阵缓存仍逐珠提交；文字布局缓存命中后仍改写布局属性。

- 新增可选 `render.canvas.gpu` 服务，保留原 C ABI 和 CPU 导出/预览路径。鲸鱼全部布局显式接入，在宿主现有 D3D11 设备上直接绘制到 GPU 纹理，生产路径不回读像素、不对结果再次转换并上传。
- 多组件共享 Direct2D 设备和字形缓存。同一批内容更新共用绘制作用域，结束后恢复完整 D3D 状态；非鲸鱼旧组件不因这个服务自动改变渲染方式。Live2D 原有独立合成路径保留。
- 点阵的亮珠、柱状与环形频谱的九切片金属柱/峰值使用小型图集及 `ID2D1SpriteBatch` 批量提交，动态帧只更新实例位置和源矩形。按实际 DPI 构建，颜色、光晕、尺寸、DPI、设备/目标变化均使缓存失效。
- 文字缓存以文字、字体、字号、布局尺寸、对齐等共同标识，不再在命中后反复改写同一 DirectWrite 布局。增加“不同尺寸不修改旧布局、同尺寸复用”的专项断言。
- 机械零件每次绘制只读取对应图片快照；图片更新由已有统一轮询和就绪回调驱动，避免每个齿轮再次扫描整组图片。
- 验证分为强制全量重绘、无变化纹理复用、33ms 音乐稳态三类。硬件查询区间与 CPU 提交分别记录；测试截图回读放在计时区间外。额外断言 GPU Canvas 不改写 CPU 哨兵缓冲、精灵确实进入一个批次，检查冷启动、675 帧 GPU 共存/重启/DPI/设备切换及 D3D 状态恢复。
- 仍保留成熟模型的 CPU 逻辑与可变形矢量（例如锦鲤脊骨）；不以取消效果或降低 33ms 物理更新频率换性能。每布局成本与最终数据记录在 `Testing/deep-whale/host-result.json`。

实现依据：[Direct2D 性能指南](https://learn.microsoft.com/en-us/windows/win32/direct2d/improving-direct2d-performance)、[Direct2D 设备上下文](https://learn.microsoft.com/en-us/windows/win32/direct2d/devices-and-device-contexts)。

## 横向占格与 Pixels 对齐

- 全部 25 个 4×1、6×1、8×1 布局使用与 Pixels `PixelLayout.h` 相同的每侧 7px 布局留白，包含 1px 重建滤波余量；实色主体至少保持 6px。运行时的左右间距为固定逻辑像素，不随组件整体缩放而增大。
- `horizontalCuts` 指定各皮肤连接边框中的安静竖条。两端、人物、圆表盘和装饰保持等比；只延展这些竖条，功能区域与命中区域使用同一重排坐标。多个表盘的延展条设在表盘之间，不将圆形拉成椭圆。
- 点阵时钟同样只延展玻璃与连接边框，5×7 字形保持方形；紧凑弹簧时钟的上梁按实际宽度绘制并缓存，六个挂点直接复用 Box2D 锚点，不改变数字、弹簧或运动范围，也不再解码旧横梁图片。皮肤重组结果仍按实际 DPI 缓存，不在每次动态更新时重新拼壳。
- 使用 `scripts/build-deep-whale-wide.ps1` 做专项验证，覆盖 25 个布局原生尺寸/DPI，以及扣除宿主 6px 后的实际内容矩形、多实例 GPU、重启、尺寸/DPI 切换与设备重建。逐帧测量可见不透明外缘，不能只检查设计 JSON 的 7px 标记。
