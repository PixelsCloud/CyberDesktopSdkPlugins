CyberDesktop System Info 1.0.0 · Windows x64 /MT

四款独立系统监控插件，尺寸按列×行：1×1、2×1、4×1、2×2。
空白区域右键 → 添加插件 → 系统监控。另行安装时在设置 → 插件中导入 .cdpkg。
右键插件砖块 → 插件设置，刷新间隔、配色和 1×1 主指标均按实例独立保存。

1×1 默认 CPU；2×1 为 CPU / RAM；4×1、2×2 为 CPU / RAM / GPU / CPU 温度。
数字全部 14px，24 段仪表均为 48px。实际宽高跟随桌面网格，不拉伸图形。
内容透明，材质由宿主负责。默认配色跟随主题，也可固定石墨 / 浅色。
CPU 温度无可靠数据时显示 0°C 占位，其他无效 / 过期数据使用 —。
GPU 占用是宿主选取的所有 GPU 中最高值；不把 GPU 温度当作 CPU 温度。

单个 protobuf 包已包含 DLL、描述、设置、说明和 SDK 许可，不依赖 Qt 或动态 VC 运行库。
依赖 Windows 系统绘图库与 Consolas 系统字体。SDK 辅助代码许可见 licenses/CyberDesktopSDK-MIT.txt。

绘制底层已迁移至公共 CyberCanvas：复用 COM/Direct2D 目标、实际 DPI 帧、透明抗锯齿、预乘读回与 PNG 导出；专用字体和布局保持原有实现。

机械系统监控为独立插件，请在控件列表中搜索“机械”后添加。
本插件固定使用原来的透明仪表样式，没有皮肤切换设置；原有实例及其设置继续保留。
