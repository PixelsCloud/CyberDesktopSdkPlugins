# 插件外观设置

`WidgetAppearance` 的字段是绘制输入，不是统一的设置页面模板。插件清单只应暴露当前渲染器实际使用的字段，标签与说明必须描述该插件中的实际用途，并同时维护中文与英文。

- 音乐频谱：`foreground` 控制柱条或径向线条；柱条的 `accent` 控制峰值标记。径向频谱只将 `secondary` 用于中心图标，没有字体设置。
- 点阵频谱：`foreground`、`accent` 分别是底部和顶部灯点颜色；不提供文字颜色或字体设置。
- 播放器：分别说明标题/唱臂/图标、歌手/时间、播放按钮/进度/唱片标签的用途。
- 相册：照片保持原色；只提供背景、照片裁切圆角和序号字体，不提供未使用的前景色。
- 键鼠统计：标题和统计说明独立于键盘/鼠标计数专用颜色。
- 时钟：区分时分数字或指针刻度、日期星期、秒针或秒数。点阵结构不会因为字体选择而改变。
- 砖块时钟：颜色用于砖墙、数字切口与砖缝，不是普通文字；没有字体和可调背景圆角。
- 系统仪表盘：名称文字可以改色，读数和弧线保留各指标配色；不暴露未使用的次要色和强调色。
- 锦鲤：前景色和字体仅用于祝福文字；鱼的花纹使用专门的设置。
- 物理挂件：颜色对应横梁、悬线、数字牌或大小挂件；没有文字的风铃不提供字体。
- 沙漏：区分沙粒/倒计时、说明、高光沙粒/框架；不同时暴露被现代配色覆盖的旧沙色预设。
- 植物：状态文字和浇水按钮可以改色，植物图片保留原配色。
- 天气与空气质量：明确标注温度、城市、污染物、含量条或图表；天气插画和空气质量等级配色保持其含义。
- 效率工具：按网速、磁盘、计时器、倒数日、待办、笔记、RSS 的实际内容命名；不用强调色的布局不显示该选项。
- 角色对话与 Live2D：文字设置只作用于对话、输入、名称或模型状态，不改变角色图片和模型。

背景渐变的终点和角度应说明仅在线性渐变模式下生效。字体说明应指出其作用的文字，避免暗示会改变 SVG 图标、图片、像素数字或模型。

保留设置键和布局 ID；移除无效控件不要求删除实例状态中的旧字段，也不得因此删除数据库列。新增布局应检查每个暴露字段在相应渲染分支中的读取和可见效果，不能直接复制其他插件的外观页面。
